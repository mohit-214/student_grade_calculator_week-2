# Student Grade Calculator

## Project Overview

The Student Grade Calculator is a Python application that allows users to enter marks for multiple students, calculate averages, assign grades, generate comments, and display class statistics.

## Features

* Multiple student support
* Grade calculation based on average marks
* Personalized comments
* Input validation
* Error handling using try-except
* Results summary table
* Class statistics generation

## Technologies Used

* Python 3
* Functions
* Lists
* Loops
* Conditional Statements
* Exception Handling
